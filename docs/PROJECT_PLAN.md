# 프로젝트 계획

## 목표

이미지 또는 짧은 영상을 휴대폰 배경화면이나 GIF로 저장하는 무료 개인용 브라우저 앱. PC와 모바일을 지원하고 GitHub Pages에서 정적으로 배포한다. 기능 확장보다 기기의 안정성과 낮은 처리 부하를 우선한다.

## Phase 1 — 현재 구현

- React / TypeScript strict / Vite / Tailwind 기반 프로젝트
- 브라우저 내부 파일 검증·이미지 디코딩·미리보기·교체·제거
- 프리셋 및 사용자 지정 해상도, 원본 해상도 옵션
- 전체 표시와 자동 색상/사용자 색상/축소 블러 배경, 위치 조절 크롭
- 고품질 보간 리사이즈와 단일 경량 선명도 필터
- PNG/JPG/WebP, 파일명/품질 설정, 최종 결과 확인과 다운로드
- 한국어 다크 테마, 반응형 화면, 모바일 하단 저장 영역
- 제한/작업 잠금/취소/오류/리소스 정리 및 문서

상태: 코드 구현 완료. 타입 검사, 소규모 안전 제한 검사, 일반 빌드 결과는 작업 보고에 기록한다. 실제 브라우저 동작과 모바일 기기 검증은 별도다.

## Phase 2 — 짧은 영상

영상 파일 선택, 브라우저 기본 video 미리보기, 시작·종료 시간 선택. 이미지 편집과 모델·자원 수명·UI를 분리한다. 코덱 지원과 파일·길이·해상도 제한을 먼저 정하며 이 단계에서 인코딩을 선행하지 않는다.

## Phase 3 — GIF

최대 5초, 기본 10FPS, 기본 폭 480px. 최대 프레임 수와 총 메모리 제한, 취소와 단계적 처리 방식을 먼저 설계한다. 필요한 최소 인코더는 별도 검토 후 선택하며 이번 프로젝트에는 설치하지 않는다.

## Phase 4 — 모바일 / PWA / 배포

실기기에서 터치, 안전 영역, 가로 화면, 다운로드를 검증하고 PWA 도입과 GitHub Pages 배포를 진행한다. 사용자 파일의 캐싱·영구 저장은 기본적으로 하지 않는다. 현재 반응형 기본 UI와 배포 안내는 Phase 1에 포함하되 PWA·실제 배포는 포함하지 않는다.

## Phase 5 — 선택적 AI 연구

먼저 성능·메모리·다운로드 크기·모바일 지원 여부를 분석한다. 사용자 승인 없이 AI 모델이나 런타임을 설치·다운로드·실행하지 않는다.

## 제외 범위

현재 영상 편집, GIF 인코딩, FFmpeg/FFmpeg.wasm, AI 업스케일링, YouTube URL 입력, 영상 AI 개선, 백엔드, 데이터베이스, 클라우드 API, 파일 업로드, 로그인, PWA는 구현하지 않는다.

## 다음 단계 전 수동 검증

작은 이미지 한 장씩만 사용하고 반복 부하 시험은 하지 않는다.

1. JPG/PNG/정적 WebP 선택, 드롭, 교체, 제거. EXIF 회전 JPEG의 해상도와 방향 확인.
2. 각 비율과 사용자 크기, 자동/사용자 색상, HEX 유효성, 블러, 크롭 양 끝 위치 확인.
3. 작은 원본 확대와 원본 크기 옵션, 한도 초과 출력의 축소 안내 확인.
4. 선명도 0/낮은 값, PNG/JPG/WebP 각각의 최종 미리보기와 다운로드 파일 확인.
5. 10MB 초과/12MP 초과/손상/위장 확장자/다중 파일 거절 확인.
6. 처리 중 중복 클릭, 탭 전환에 따른 중단 안내, 실패 후 수동 재요청 확인.
7. PC/모바일 너비, 키보드 접근, 모달 포커스와 Escape, 가로 스크롤 없음 확인.
8. 모바일 Safari 다운로드/블러/WebP 지원, 네트워크 패널에서 파일 전송 없음 확인.

## 확장 원칙

`features/image`는 이미지 전용으로 유지한다. `features/video` 및 `features/gif`는 각 Phase 승인을 받은 뒤 추가한다. 처리 도구는 공유하더라도 이미지와 영상의 작업을 동시에 실행하지 않는 전체 작업 제어를 유지한다.
